# Source-frozen local verification

`npm run validate:local` executes the existing asset preparation, full `check` and complete Chromium/WebGL suite without GitHub Actions. It does not install dependencies, provision a runner, access GitHub, push code, merge, or change billing or scheduled tasks. Use the project's installed Node/dependency/browser versions and a working local WebGL display environment. A WebGL initialization failure is an environment failure, not a passing gameplay result.

The command acquires a local exclusive lock under `.local-validation/`, prepares the hash-pinned assets, then records the Git HEAD/tree and SHA-256 of every tracked or nonignored source file. It writes the complete source snapshot, including new files and a tracked-file patch, **before** starting the long check/browser commands. The Git tree identifies the committed baseline; the source manifest identifies the actual tested working files. If any source file changes during validation, the final result is failed rather than attributing earlier evidence to a later source tree.

Each command writes its exit code and log. The browser step retains the original single worker, fixtures, interaction assertions, deadlines, viewport and trace policy; it adds JSON and HTML reporting and rejects focused `.only` tests, not retries or a different game. Final JSON statistics must contain executed passing cases with no failures, skips, flaky results or global errors. Failure records and any generated test artifacts remain available. Incomplete/interrupted reports are not acceptance. The script's metadata is local evidence, **not** a GitHub check or an independent main CI run.

All browser fixture writes target the managed server's dedicated `data/latticefolk.e2e.sqlite`. They never reset `data/latticefolk.sqlite`; the normal launcher and existing saves are unchanged. Tests still share one world and therefore run serially. Reusing an existing server remains disabled. Do not run destructive browser fixtures against a manually configured production server.

The output directory contains `result.json`, `source-manifest.json`, `source/`, `working.patch`, step logs, `playwright.json`, `playwright-report/` and copied `test-results/` when available. Preserve this directory and a full source archive or Git bundle at a handoff; a partial success log alone cannot reconstruct the implementation. If a local lock remains after abrupt termination, establish that the recorded process is no longer running before removing that stale lock. Never automatically start a second run over an active validation.

In the 2026-09-29 Actions-allowance constraint, retain the same canonical draft PR and explicitly distinguish local evidence from quota-blocked remote checks. A deliberate `[skip ci]` checkpoint does not pass required checks or waive the existing guarded-merge and independent-main validation requirement. No automatic quota-reset watch or paid fallback is implied. This command leaves visual review to the actual inspected screenshots and does not claim all Phase B poses, C/D journeys or unscripted free play complete.
